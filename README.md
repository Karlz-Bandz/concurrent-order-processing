# Concurrent Order Processing System

A Java-based order processing system focused on multithreading, concurrency, synchronization, and asynchronous processing.

## Project Goal

The goal of this project is to build a realistic order processing system while exploring Java concurrency and gradually introducing production-oriented backend technologies.

## Planned Technologies

* Java 21
* Maven
* Spring Boot
* PostgreSQL
* Kafka / RabbitMQ
* Docker
* JUnit

## Planned Topics

* Threads and Runnable
* BlockingQueue
* Producer-Consumer pattern
* ExecutorService
* Thread pools
* Race conditions
* Synchronization
* Concurrent collections
* Asynchronous processing
* Idempotency
* Retry mechanisms
* Database transactions
* Message brokers
* Testing concurrent applications

## Project Development

The project will be developed incrementally, starting with pure Java concurrency and gradually evolving into a Spring Boot backend application.
